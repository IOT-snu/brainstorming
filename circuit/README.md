# Energy-measurement circuit (KiCad)

`ina219_energy_monitor.kicad_sch` is the wiring from the progress report: an INA219 current sensor in series with an
ESP32 node's 5 V supply, read over I2C by a second ESP32. Open `ina219_energy_monitor.kicad_pro` in KiCad 7, 8 or 9
(or open the `.kicad_sch` directly). `circuit_preview.png` is the same circuit as a picture.

| Net | Connects |
|---|---|
| 5V_IN | supply +5V to INA219 VIN+ |
| NODE_5V | INA219 VIN- to the node under test (VIN 5V pin) |
| +3V3 | monitor 3V3 to INA219 VCC (and the optional pull-ups) |
| SDA / SCL | INA219 to monitor GPIO21 / GPIO22 (and the optional pull-ups) |
| GND | all grounds |

Notes
- The file is generated by `make_kicad.py` (run it to rebuild). It was checked with a schematic parser and a connectivity
  script, but it has not been opened in KiCad itself yet. If KiCad complains, tell us the version and message.
- Symbols are simple functional blocks (no footprints). Assign footprints before making a PCB, or just use breakout boards.
- R1 and R2 (4.7 kohm I2C pull-ups) are only needed if the INA219 module has none.
- Proposed wiring, not built or tested. Check every pin against your module's datasheet before powering it.
