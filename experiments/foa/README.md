# Fleet-Orthogonal Adaptation: simulator and experiments

Everything behind the paper in `paper/main.pdf`. Python 3.12, numpy, matplotlib, pytest.

## Data

```bash
python3 experiments/get_nbaiot.py --fleet
```

All nine N-BaIoT devices, streamed from UCI (about 2 hours at the server's speed; resumes after a dropped
connection). CESNET-TimeSeries24: download `ip_addresses_sample.tar.gz`, `ids_relationship.csv`,
`times.tar.gz` from Zenodo record 13382427 into `experiments/data/cesnet/` and unpack the two archives.
Data is not committed.

## Code

| File | What it does |
|---|---|
| `data.py` | N-BaIoT loading, physically modelled drift on raw Kitsune features, fleet-shared 16-D whitened space, per-device streams |
| `cesnet.py` | CESNET streams: one learning cycle per real day, modelled scanner attack |
| `detector.py` | Centroid detector and the signature-free local proposal (with the robust agreement projection) |
| `foa_rule.py` | The FOA update (Algorithm 1), a pure function mirrored by the ESP32 C code |
| `robust.py` | Geometric median (Weiszfeld), ball projection, Minsker constant |
| `gossip.py` | 92-byte HMAC-SHA256 frames, byte-identical to the firmware |
| `attacks.py` | Boundary, core, mimicry, multi-direction, aligned, pulsing, decoy; Byzantine and Sybil |
| `fleet.py` | Fleet simulator and every rule compared (static, naive, single device, clipping, frozen reserve, alarm switch-off, outlier-ratio gate, TOA, CIoTA-style, FOA and variants) |
| `experiments.py` | E1 to E11 (task grids, paired attacker-free controls, held-out seeds) |
| `synth.py`, `synth_experiments.py` | Synthetic fleet with known geometry: theory checks S1 to S3 |
| `analysis_e0.py` | Data sanity: variance kept, detection, attack margins, drift strength |
| `figures.py`, `style.py` | Every paper figure, one visual system |
| `tests/test_foa.py` | 16 unit and property tests (bounds, gossip rejections, freeze immunity, determinism) |

## Reproduce

```bash
cd experiments/foa && python3 -m pytest -q tests
```
```bash
cd experiments/foa && python3 analysis_e0.py && python3 synth_experiments.py
```
```bash
cd experiments/foa && python3 experiments.py all --seeds 10 --jobs 9
```
```bash
cd experiments/foa && python3 figures.py && python3 ../../paper/make_numbers.py
```
```bash
cd paper && cp ../experiments/foa/figures/*.pdf figures/ && tectonic main.tex
```

The full matrix is about 18,500 simulated fleet runs and takes about 45 minutes on a 10-core laptop. `results/*.csv`
hold every run's metrics; the `.pkl` files (with time traces) are regenerated by the commands above and
are not committed because of their size.

## Experiments

| ID | Question | Fleet | Runs |
|---|---|---|---|
| E0 | Is the shared space adequate, how strong is the drift | 9 devices | - |
| E1 | Liveness: shared and device-only honest drift, no attacker | 9 | 820 |
| E2 | Poisoning without drift (3 attackers x 4 shares x 7 victims) | 9 | 5,880 |
| E3 | Poisoning hidden in strong shared drift | 9 | 6,720 |
| E4 | Monoculture botnet vs same-model consensus | 12 (4 models x 3) | 300 |
| E5 | Freeze attack with loud decoys | 9 | 960 |
| E6 | Byzantine peers, Sybil and replay, frame loss | 9 | 440 |
| E7 | Budget sweep: safety vs liveness | 9 | 960 |
| E8 | Ablations and adaptive attackers | 9 | 1,320 |
| E9 | Joining device with a poisoned first window | 12 | 160 |
| E10 | Four-node fleet (testbed size) | 4 | 210 |
| E11 | Real drift, 40 weeks of CESNET, 12 IPs | 12 | 695 |
| S1-S3 | Theory checks on known geometry | synthetic | 330 + 2,000 trials |

Protocol: design choices were made on seeds 0 and 1 only; all reported numbers use seeds 2 to 11. Victims
must have their target attack at least 1.3 alarm radii out. Compromise is counted only when the attacked
run loses detection that its attacker-free twin keeps. See `RESEARCH_LOG.md` for every decision and why.
